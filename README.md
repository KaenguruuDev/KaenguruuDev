### Projects

**[`BeutelBot`](https://bot.kaenguruu.dev)**

A discord bot focused on increasing engagement in smaller discord servers. While it can be added to servers, I do not recommend it as it isn't quite ready yet.

**[`NoModLeftBehind`](https://github.com/KaenguruuDev/NoModLeftBehind)**, **[`SodiumDynamicLights`](https://github.com/KaenguruuDev/SodiumDynamicLights)**

Two NeoForge 1.21.1 projects developed specifically for the [Create: Attack 7](https://create-n-beyond.de/create-attack-7) modpack. `NoModLeftBehind` is a custom mod, while `SodiumDynamicLights` is a fork containing a specific fix for a lighting-related performance issue with *Create: Aeronautics* entities.

Both are intentionally limited to the modpack's current Minecraft version rather than maintained as general-purpose, multi-version mods.
